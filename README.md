# AI Social Media Automation Platform

🚀 AI Social Media Automation Platform is a full-stack SaaS application that simplifies social media management through AI-powered content generation and automated post scheduling. Users can connect multiple social media accounts, generate engaging posts using AI, and schedule content across platforms from a unified dashboard.

Built with the MERN Stack, the platform integrates modern APIs to deliver a scalable, secure, and responsive solution for content creators, businesses, and marketing teams.

## Features

- 🤖 AI-powered social media post generation
- 📅 Schedule posts across multiple platforms
- 🔗 Connect and manage multiple social media accounts
- 📊 Interactive dashboard for content management
- 🔐 Secure JWT-based authentication and user management
- ⚡ RESTful APIs with Express.js and Node.js
- 📱 Fully responsive UI built with React and Tailwind CSS
- 🚀 Production-ready SaaS architecture
- 🔍 AI-assisted code quality using CodeRabbit
- 🔄 Social media automation via Zernio API

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Tailwind CSS
- OpenAI API
- Zernio API
- CodeRabbit

## Architecture

1. Users authenticate securely using JWT.
2. Connect multiple social media accounts.
3. Generate AI-powered content using the OpenAI API.
4. Schedule posts through the Zernio API.
5. Manage all campaigns and posts from a centralized dashboard.
6. Backend APIs handle authentication, scheduling, and data persistence.
